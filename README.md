# Проект "Онлайн магазин"

## Описание
Это онлайн магазин для магазинных дел.

## Установка

1. Клонируйте репозиторий.
```
git clone https://github.com/neron262013-sudo/online_shop.git
```
2. Установите зависимости.
```
pip install -r requirements.txt
```

## Список зависимостей
- Django==6.0.5

## Использование
1. Запустите сервер.
```
python manage.py runserver
```
2. В поле адреса добавьте:
- Главная страница
```
/catalog/home/
```
- Контакты
```
/catalog/contacts/
```
